# Perustietoa 
Tämä projekti on toteutettu Next.js:n virallisen “ACME Dashboard” -tutorialin pohjalta. Sovellus toimii laskutusjärjestelmänä, jossa voidaan hallita laskuja sekä asiakastietoja dashboard-näkymän kautta.

Projektin tavoitteena oli oppia modernien full stack -websovellusten kehittämistä käytännössä Reactin, Next.js:n sekä PostgreSQL-tietokannan avulla.

**Projektissa käytettiin muun muassa:**

- React
- Next.js App Router
- TypeScript
- Tailwind CSS
- PostgreSQL
- Vercel

# Toteutukset
Projektissa toteutettiin:

- kirjautumisjärjestelmä
- dashboard-näkymä
- laskujen luonti, muokkaus ja poistaminen
- reaaliaikainen hakupalkki
- pagination-toiminto
- virheidenhallinta
- datan validointi

# Käyttöönotto
Käynnistäminen lokaalisti:
1. npm install -g pnpm
2. pnpm install
3. pnpm dev
4. Avaa selain ja osoite: http://localhost:3000
5. Muista määritellä ympäristömuuttujat postgre sekä AUTH_SERCET varten

# Yhteenveto

Projektin aikana opin paljon uusia full stack -kehitysmenetelmiä ja teknologioita. Erityisesti Reactin, Next.js:n, TypeScriptin sekä PostgreSQL:n käyttö tuli tutummaksi.

Projektin aikana tuli ratkaistua myös useita build- ja deployment-ongelmia, mikä auttoi ymmärtämään paremmin modernien web-sovellusten rakennetta sekä frontendin ja backendin yhdistämistä.”
